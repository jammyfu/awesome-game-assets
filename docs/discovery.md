# Browsing, original previews and use rights / 浏览、原图和使用条件

## Ordering / 排序

Every category shows up to 15 rows initially; remaining rows stay in a native GitHub disclosure and expand into the same comparison table. All 297 entries remain in both languages. GitHub rows sort by observed **total stars**, descending, with original data order breaking ties. Each of the 250 repository counts was read from its public repository page on 2026-11-12; exact source and timestamp are stored per entry in `data/entries.json`. The 47 non-GitHub sources have no comparable metric and follow, keeping their data order. A missing value is not zero. This is cumulative popularity, **not recent growth or a cross-platform ranking**.

每类默认最多 15 条，其余点击展开仍是表格，297 条全部保留。250 个 GitHub 项目按 2026-11-12 抓取的累计星标倒序，同数保留原顺序；47 个非 GitHub 网站无可比指标，随后显示。不能将这份快照称为近期趋势或跨平台热榜。

## Original previews / 原项目图片

Use the project's original screenshot, sample, demo or official preview first. Previews are hotlinked, credited and open at the original project. They are **not copied into this repository**, and display here is not a grant to reuse them. A code license alone is not a media license. Explicit reuse terms are kept when verified; otherwise the original source controls. Do not remove credits, watermarks or impose a generic code license on someone else's images.

优先原项目截图、素材样例、演示或官方展示图，直接引用原地址并署名，不将第三方图复制进仓库。展示不等于授予再使用许可，代码许可不代表媒体许可；需要取用时查看原始页面。身份标识会明确标注“项目标识，非素材效果”。

This correction restores 227 reviewed original image references (including 41 clearly identified project identities where no better preview was verified), replaces 14 poor/logo/badge selections with original visual examples, and replaces 13 generated stand-ins with original references. Three unsuitable original selections remain source-only. The other 67 entries have no usable static original preview verified after a first pass of their official README/site; they link to the project instead of showing invented results. This is not a claim that no image exists anywhere.

本轮恢复 227 个原项目图片引用，其中 41 个为明确标注的项目标识；将 14 个不合适的图替换为真实展示，将 13 个生成占位替换为原图。另 3 个不合适原图只保留来源入口，67 项在首轮原站与 README 检查后尚未核实可用静态原图。这不代表全网都没有图片。

The generated hero is retained as project branding. Generated category art and row stand-ins are no longer shown in the catalog. Historical generated files/prompts are retained for provenance, not presented as project output. No new synthetic asset preview was generated.

保留生成头图作为项目品牌；目录不再显示生成分类插画和生成素材占位。历史文件和提示词保留溯源，不当作原项目效果。本轮未生成替代素材图。

## Plain-language use conditions / 人话许可

The table starts with practical use conditions, then places the canonical license name in parentheses on the next line, linked to the original terms. Commercial use is not the same as unrestricted redistribution. Code, weights, outputs, art and datasets may have different conditions. Summaries do not override the linked terms; check the exact download before shipping. In curated-list rows the license applies to the list text, not every linked resource.

表格先说能否商用、须否署名、分发时的主要义务，再换行括号列协议。商用不等于可以无条件转卖；代码、权重、输出、美术和数据可能有不同要求。资料清单的许可仅约束清单文字，不覆盖所链接全部素材。
